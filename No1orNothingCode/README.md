# No.1orNothing ｜ GameCreateWater 担当ソース

Unity の対戦ゲームで、プレイヤーがスポットライトに入ったときの得点判定、対戦中のイベント進行、ラウンドごとの得点を振り返るリザルト表示などに携わりました。

## 代表的な実装

| 機能 | コードの見どころ | 担当履歴の例 |
|---|---|---|
| [スポットライト内の得点判定](Source/Scripts/SpotLight/SpotLightScore.cs) | エリアに出入りしたプレイヤーを登録・解除し、ライト内での継続加点とシャッター時の一括加点を扱います。 | `829f99e3` |
| [対戦イベントの進行](Source/Scripts/EventManager/EventManager.cs) | Inspector で設定した時間とイベント番号を使い、コルーチンで経過時間を計測して対応するオブジェクトを生成します。 | `6f419a07` |
| [リザルトの折れ線描画](Source/Scripts/Result/ScoreLineCreate.cs) | ラウンド間の得点座標を補間して LineRenderer の線を段階的に伸ばし、各点にプレイヤーのアイコンを表示します。 | `6308711b` |

## 収録範囲

[担当履歴一覧](Contributions.md)に、採録した全 49 ファイルと本人の変更コミットを記載しています。ソースはチームで統合した `origin/main` の `8268c911` 時点の版です。本文の日本語を読みやすくするため、配布用コピーの文字コードを UTF-8 に統一しました。

Unity 6000.0.46f1 を使用しています。`Source/` 以下は元プロジェクトの `Assets/` 以下と同じ配置です。コード閲覧用の抜粋で、ゲームの実行には元プロジェクトのシーン、Prefab、パッケージなどが必要です。
